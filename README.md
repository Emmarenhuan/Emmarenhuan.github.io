# Meiying Ren 个人主页

## 修改内容
只需要编辑 index.html 顶部 `const SITE = { ... }` 里的文字。
- 图片/视频放进 assets/ 文件夹，在 SITE 里写 "assets/文件名"
- **文字** = 加粗
- 新增项目：复制一个 { title: ..., ... } 整块，改内容

## 本地预览
双击 index.html 用浏览器打开即可。

## 免费上线（GitHub Pages）
1. 注册 GitHub，新建仓库，名字必须是：你的用户名.github.io（Public）
2. 仓库页面 → Add file → Upload files，把 index.html 和整个 assets 文件夹拖进去 → Commit
3. 约 1 分钟后访问 https://你的用户名.github.io
4. 以后修改：在 GitHub 网页上点 index.html → 铅笔图标编辑 → Commit
